FACTUPSYWARE — INFORME TÉCNICO
================================================================================

DESCRIPCIÓN GENERAL
--------------------
Sistema de facturación (Django) para un consultorio/servicio profesional,
con integración a ARCA (ex AFIP) para facturación electrónica, gestión de
clientes, servicios, facturas y tickets de soporte.

STACK
-----
- Backend: Django (Python), con apps propias: clientes, arca, servicios,
  facturas, tickets.
- Certificados propios para conexión con ARCA (carpeta certificados/).
- Backups automatizados (carpeta backups/).
- Frontend: templates Django + static (sin framework JS pesado detectado).

ESTRUCTURA DE APPS
-------------------
- clientes: modelo Cliente.
- arca: EmpresaConfig — configuración de la empresa para integración ARCA
  (facturación electrónica, CUIT, certificados).
- servicios: modelo Servicio (catálogo de servicios facturables).
- facturas: Factura, FacturaItem — emisión de facturas con ítems.
- tickets: Ticket, TicketEvento — sistema de soporte/incidencias con
  seguimiento de eventos por ticket.

FUNCIONALIDADES DETECTADAS
---------------------------
- Alta y gestión de clientes.
- Configuración de datos de la empresa para facturación electrónica ARCA.
- Catálogo de servicios.
- Emisión de facturas con múltiples ítems.
- Sistema de tickets de soporte con historial de eventos.
- Backups del sistema.
